# Hindi and Hindi-English Pipeline Helpers

This directory contains scripts for Hindi/Hindi-English data preparation,
keyword extraction, stance preparation, and visualization.

## Contents

| Path | Purpose |
| --- | --- |
| `prepare_hindi_data.py` | Prepares Hindi data files for downstream analysis. |
| `prepare_for_stance.py` | Formats Hindi/Hindi-English data for stance inference. |
| `keyword_extractor_v2.py` | Extracts keyword-level subsets for Hindi data. |
| `hindi_data/` | Translation/evaluation helper scripts. Large CSV inputs are ignored. |
| `extracted_by_keyword/` | Keyword ID lists and local extracted tweet data. Large CSV extracts are ignored. |
| `visualisations/` | Hindi-English comparison plotting scripts and generated compact figures. |

The repository tracks scripts, ID lists, and compact figures. Large translated
datasets, extracted tweet CSVs, and archives remain local.
