# Final Results and Visualization Regeneration

This folder contains final plotting scripts, merge/filter utilities, and compact
publication-facing outputs for the English and Hindi-English stance analyses.

## Key Files

| Path | Purpose |
| --- | --- |
| `merge_stance_csvs.py` | Merges stance outputs for final analysis. |
| `filter_keywords.py` | Filters final stance outputs by selected keywords. |
| `codes/` | Plotting scripts for stacked stance plots, butterfly plots, normalized divergence, bucket tables, and Hindi-English comparisons. |
| `codes/output/` | Selected regenerated figures and compact metrics. |

Large full-result CSVs and archives are ignored. Scripts and compact visual
outputs are intended to stay in Git.
