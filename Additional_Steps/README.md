# Additional Research and Revision Steps

This folder contains supplementary analysis added around multilingual processing,
reviewer requests, cross-checking, temporal splits, and final validation.

## Contents

| Directory | Contents |
| --- | --- |
| `Translating/` | Multilingual routing, Hindi/Hinglish translation, merge, resume, and audit notebooks. |
| `Crosschecking_and_Joining/` | Scripts for joining translated and English outputs, checking coverage, temporal splits, and final stance plots. |
| `bucket_analysis/` | Sampling scripts and compact summaries for bucket-level tweet review. |

Large translated datasets, cross-checking CSV dumps, model files, and runtime
logs are excluded by `.gitignore`. The scripts, notebooks, summaries, and
publication-facing figures are kept in Git where practical.
