# Late-Stage Review Analyses

This folder contains late-stage analysis scripts for bucket tweet extraction,
post-analysis accuracy checks, and statistical significance testing.

| Directory | Contents |
| --- | --- |
| `extracting tweets for buckets/` | Sampling and extraction scripts for manual bucket review. |
| `post_analysis_accuracy/` | Accuracy checks and compact reports. |
| `significance_testing/` | Significance tests, language comparisons, mixed-effects checks, and visualization scripts. |

The folder name is preserved for continuity with the local project history.
Scripts and compact reports should be committed; generated bulky data outputs
should remain local.
