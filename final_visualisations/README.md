# Final Visualisations

This folder contains publication-facing plots and helper files for final
visual checks. The matching large final data CSV under `final_data/` is ignored,
while compact figures, notebooks, and scripts are kept in Git.

Use the plotting scripts in `final_results+visualisations_folder/codes/` and
`codes/7_visualisations/` to regenerate figures after restoring the excluded
input data.
